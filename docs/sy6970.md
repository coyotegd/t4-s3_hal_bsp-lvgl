# SY6970 Power Management IC (PMIC) Guide

## 5A, Single Cell Li-Ion Switching Charger with I2C Control and Power Path Management

## Overview

The SY6970 is a fully-integrated switching battery charger designed for single cell Li-Ion and Li-polymer batteries. It's used on the LilyGo T4-S3 board to manage battery charging, power path control, and USB power negotiation.

### Key Capabilities

- **Charging:** Up to 5A fast charging current (1.5MHz switching)
- **Power Path Management:** System powered even with depleted/missing battery
- **USB Support:** BC1.2 (DCP/CDP/SDP) detection, USB 2.0/3.0 power compliance
- **OTG Mode:** 5V output, up to 2.4A (500kHz boost converter)
- **I2C Control:** Fully programmable via I2C interface (7-bit address: 0x6A)
- **Safety:** JEITA compliance, thermal regulation, overcurrent/overvoltage protection
- **Battery Monitoring:** Voltage, temperature (NTC), and current measurements

### Package

- QFN 4mm x 4mm, 24-pin
- Exposed thermal pad for heat dissipation

## Pin Configuration

### Critical Pins

| Pin   | Name                 | Function                       | Notes                                                 |
| ----- | -------------------- | ------------------------------ | ----------------------------------------------------- |
| 1     | BUS                  | USB/DC input power             | 3.9V-14V input range                                  |
| 2-5   | /CE, /QON, OTG, STAT | Control and status outputs     | Active-low chip enable, reset, OTG enable, status LED |
| 6-7   | DP, DM               | USB data lines                 | BC1.2 detection                                       |
| 8     | ILIM                 | Input current limit resistor   | 5.52kΩ typical for BC1.2                              |

| 12    | INT                  | Interrupt output               | Open-drain, active-low                                |

| 15-16 | SYS                  | System power output            | Powers the device                                     |

### External Components

```text
Required Components:
- BUS:  1µF input capacitor (ceramic, 16V+)
- PMID: 6.8µF ceramic capacitor
- BAT:  10µF ceramic capacitor
- SYS:  10µF ceramic capacitor
- REGN: 4.7µF ceramic capacitor
- BST:  47nF ceramic capacitor (to LX)
- LX:   1µH inductor (DCR <30mΩ, rated for 6A+)
- ILIM: 5.52kΩ resistor to ground
- NTC:  10kΩ thermistor (103-AT) with 31.23kΩ pull-up to REGN
```

## I2C Register Map (Key Registers)

### Register 0x00: Input Source Control

| Bit | Name        | Function                    | Default        |
| --- | ----------- | --------------------------- | -------------- |
| 7   | EN_HIZ      | Enable High-Impedance Mode  | 0 (disabled)   |
| 6   | EN_ILIM     | Enable ILIM Pin Control     | 1 (enabled)    |
| 5:0 | IINLIM[5:0] | Input Current Limit         | 000010 (500mA) |

**Input Current Limit Values:**

- 000000 = 100mA
- 000001 = 150mA
- 000010 = 500mA (default)
- 011111 = 3250mA
- Step: 50mA

### Register 0x02: Charge Current Control

| Bit | Name       | Function              | Default       |
| --- | ---------- | --------------------- | ------------- |
| 7   | FORCE_DPDM | Force DP/DM Detection | 0             |
| 6:0 | ICHG[6:0]  | Fast Charge Current   | 0000000 (0mA) |

**Fast Charge Current Values:**

- Step: 64mA
- Range: 0mA - 5056mA
- Formula: Current = ICHG × 64mA

### Register 0x04: Charge Voltage Control

| Bit | Name       | Function                   | Default        |
| --- | ---------- | -------------------------- | -------------- |
| 7:3 | VREG[4:0]  | Charge Voltage Limit       | 10110 (4.208V) |
| 1   | TOPOFF_TMR | Top-Off Timer              | 0 (15min)      |
| 0   | VRECHG     | Battery Recharge Threshold | 0 (100mV)      |

**Charge Voltage Values:**

- Base: 3.840V
- Step: 16mV
- Range: 3.840V - 4.608V
- Formula: Voltage = 3.840V + (VREG × 16mV)
- Default: 4.208V (VREG = 10110 = 23, 3.840V + 23×16mV = 4.208V)

### Register 0x06: Timer Control

| Bit | Name           | Function            | Default       |
| --- | -------------- | ------------------- | ------------- |
| 7   | EN_TIMER       | Enable Safety Timer | 1 (enabled)   |
| 6:5 | CHG_TIMER[1:0] | Fast Charge Timer   | 10 (12 hours) |
| 3   | WATCHDOG[2]    | Watchdog Timer MSB  | 0             |
| 2:1 | WATCHDOG[1:0]  | Watchdog Timer LSBs | 01 (40s)      |

**Watchdog Timer Values:**

- 000 = Disabled
- 001 = 40s
- 010 = 80s
- 011 = 160s

### Register 0x07: Charge Control

| Bit | Name          | Function                     | Default       |
| --- | ------------- | ---------------------------- | ------------- |
| 5:4 | TREG[1:0]     | Thermal Regulation Threshold | 00 (120°C)    |
| 2   | BATFET_DIS    | Force BATFET Off             | 0 (enabled)   |
| 1   | BATFET_DLY    | BATFET Turn-Off Delay        | 0 (immediate) |
| 0   | BATFET_RST_EN | BATFET Reset Enable          | 1 (enabled)   |

### Register 0x08: System Status

| Bit | Name           | Function                                                                  |
| --- | -------------- | ------------------------------------------------------------------------- |
| 7:6 | VBUS_STAT[1:0] | VBUS Status (00=No input, 01=USB, 10=Adapter, 11=OTG)                     |
| 5:4 | CHRG_STAT[1:0] | Charge Status (00=Not charging, 01=Pre-charge, 10=Fast charge, 11=Done)   |
| 3   | PG_STAT        | Power Good Status                                                         |
| 2   | VSYS_STAT      | System Voltage Regulation Status                                          |

### Register 0x0A: New Fault Status

| Bit | Name            | Function                        |
| --- | --------------- | ------------------------------- |
| 7   | VBUS_OVP        | Bus Overvoltage Fault           |
| 6:5 | TSHUT_STAT[1:0] | Thermal Shutdown Status         |
| 4   | BATOVP          | Battery Overvoltage             |
| 2   | TMR_FAULT       | Charge Safety Timer Expiration  |

### Register 0x0B: Vendor/Part/Revision

| Bit | Name     | Function                      |
| --- | -------- | ----------------------------- |
| 7:2 | PN[5:0]  | Part Number (111010 = SY6970) |
| 1:0 | REV[1:0] | Device Revision               |

## Common Programming Sequences

### 1. Initialize Charger (First Boot)

```c
// Disable watchdog (important!)
write_register(0x07, 0x8D);  // Disable watchdog, BATFET enabled

// Set input current limit (e.g., 1500mA for BC1.2)
write_register(0x00, 0x5E);  // 1500mA = (1500-100)/50 = 28 = 0x1C, shifted: 0x5E

// Set charge voltage (e.g., 4.208V default)
write_register(0x04, 0xB2);  // 4.208V = VREG=23

// Set charge current (e.g., 1000mA for 2000mAh battery)
write_register(0x02, 0x0F);  // 1000mA = 1000/64 = 15 = 0x0F

// Enable charging
write_register(0x03, 0x1A);  // Enable charging, OTG disabled
```

### 2. Read Charge Status

```c
uint8_t status = read_register(0x08);
uint8_t charge_state = (status >> 4) & 0x03;
// 0 = Not charging
// 1 = Pre-charge (< 3.0V)
// 2 = Fast charge
// 3 = Charge termination done
```

### 3. Check for Faults

```c
uint8_t fault = read_register(0x0A);
if (fault & 0x80) {
    // VBUS overvoltage
}
if (fault & 0x04) {
    // Safety timer expired
}
```

### 4. Enter OTG Mode (5V Output)

```c
// Configure OTG voltage (default 5.0V is fine)
write_register(0x09, 0x97);  // 5.0V OTG

// Enable OTG mode
write_register(0x03, 0x2A);  // OTG_CONFIG=1, CHG_CONFIG=01
```

### 5. Shipping Mode (Ultra-Low Power)

```c
// Disconnect battery from system
write_register(0x07, 0x5B);  // BATFET_DIS=1, force BATFET off
// Device enters <1µA leakage mode
// Wake up by connecting USB or toggling /QON
```

## Power Path Management Behavior

### Normal Operation (Battery Present, USB Connected)

1. **Input Priority:** System powered from USB first
2. **Charging:** Excess current charges battery
3. **Load Sharing:** If system load exceeds input limit, battery supplements power
4. **Minimum System Voltage:** Maintained at ≥3.5V regardless of battery voltage

### Battery Depleted/Removed

- System remains powered from USB
- Converter maintains ≥3.5V on SYS
- Battery disconnected until voltage recovers (UVLO ~2.8V)

### USB Disconnected (Battery Only)

- BATFET connects BAT to SYS directly
- System voltage = Battery voltage (minus BATFET resistance)
- No boost converter active (battery must be >3.5V for system operation)

## USB Detection (BC1.2)

The SY6970 automatically detects USB source type via DP/DM:

| Type                           | Input Current Limit               | DSEL Pin     |
| ------------------------------ | --------------------------------- | ------------ |
| SDP (Standard Downstream Port) | 500mA (USB 2.0) / 900mA (USB 3.0) | High (float) |
| CDP (Charging Downstream Port) | 1500mA                            | High (float) |
| DCP (Dedicated Charging Port)  | 1500mA                            | High (float) |
| HVDCP (High Voltage DCP)       | Programmable                      | Low          |
| Non-Standard Adapter           | Programmable                      | High (float) |

**Detection Process:**

1. USB connected → DSEL pulls low (detection in progress)
2. After ~1 second → detection completes
3. DSEL returns high (except HVDCP)
4. I2C register 0x08[7:6] reflects source type

## JEITA Compliance (Temperature-Based Charging)

The SY6970 supports JEITA charging profile via NTC thermistor:

| Temperature Range    | Behavior                              |
| -------------------- | ------------------------------------- |
| < 0°C (Cold)         | Charging suspended                    |
| 0°C - 10°C (Cool)    | Reduced charge voltage (4.1V)         |
| 10°C - 45°C (Normal) | Full charge voltage (4.2V/4.35V/etc.) |
| 45°C - 60°C (Warm)   | Reduced charge voltage (4.1V)         |
| > 60°C (Hot)         | Charging suspended                    |

**Implementation:**

- 10kΩ NTC thermistor (Beta 3950K, 103-AT standard)
- Pull-up resistor: 31.23kΩ to REGN
- Voltage divider read via REGN/NTC pins
- Thresholds configured in Register 0x06

## Safety Features

### Protections

1. **Input Over-Voltage:** 14V ±100mV, automatic shutdown
2. **Battery Over-Voltage:** Configurable (default 4.208V + overshoot)
3. **System Over-Voltage:** 14.3V typical shutdown
4. **Thermal Regulation:** Reduces current at 120°C (programmable)
5. **Thermal Shutdown:** 145°C emergency shutdown
6. **Watchdog Timer:** System reset if not serviced (default 40s)
7. **Safety Timer:** Charge timeout (default 12 hours fast charge)

### Status Reporting

- **STAT Pin:** LED output (Low=charging, Blink=fault, High=done/no USB)
- **INT Pin:** Interrupt on fault/status change (active-low, open-drain)
- **I2C Registers:** Detailed status and fault reporting

## Typical Application Notes

### Charge Current Selection

For optimal battery life:

- **Fast Charge:** 0.5C (e.g., 1000mA for 2000mAh battery)
- **Pre-Charge:** 0.1C (e.g., 200mA for 2000mAh)
- **Termination:** 0.05C (e.g., 100mA for 2000mAh)

### Thermal Considerations

- Ensure good thermal contact between exposed pad and PCB ground plane
- Use thermal vias under exposed pad (minimum 4 vias, more is better)
- Keep high-current traces short and wide (LX, BAT, SYS, PGND)
- Consider heat dissipation: At 5A charging, IC dissipates ~1-2W

### PCB Layout Guidelines

1. **Star-ground:** Connect BUS/BAT/SYS capacitor grounds together, then to IC PGND
2. **Keep LX traces short:** Minimize switching node area to reduce EMI
3. **Component placement:** Input cap near BUS, output caps near BAT/SYS
4. **I2C/INT routing:** Keep away from LX switching node
5. **Thermal pad:** Solder well, use solder mask relief

## Troubleshooting

### Device Not Charging

- Check VBUS voltage (>3.9V required)
- Verify /CE pin is low (chip enable active)
- Read Register 0x08 for charge status
- Check Register 0x0A for fault conditions
- Verify battery voltage (must be >2.8V to start charging)

### Charging Too Slow

- Verify input current limit (Register 0x00)
- Check if thermal regulation active (Register 0x08[2])
- Measure actual VBUS voltage (should match USB source rating)
- Check system load (high load reduces charge current available)

### System Resetting Randomly

- **Most likely:** Watchdog timer not being serviced
- **Solution:** Disable watchdog (Register 0x07[3:1] = 000) or service every 20-30 seconds
- Alternative: Check for input voltage instability

### Battery Voltage Wrong

- Verify charge voltage setting (Register 0x04[7:3])
- Check NTC thermistor connection (JEITA may reduce voltage)
- Measure at BAT pins directly (not through wires with voltage drop)
